# 0035. The default tree list shows only the biggest tree

The default branches list hides a tree when a bigger tree in the same list holds all its ayat. The bigger tree already draws those ayat, so a second card for them repeats the same ayat and adds review work. The smaller tree may share more words between its ayat. The list still shows only the bigger one.

The hidden tree's ids and wording move to the bigger tree. Its link, a bookmark saved under it and a search for its phrase open the bigger tree. Two trees with the same ayat both stay, and so does a tree with any ayah outside the bigger tree.

Trees the owner dropped take no part: they hide nothing and nothing hides them. The list of every kind of tree keeps the smaller trees.
