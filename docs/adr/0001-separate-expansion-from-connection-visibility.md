# Separate person expansion from connection visibility

Exploration gives each subject (person, battle, title, or event) independent
relationship choices and retains the subjects already revealed when another
subject's relationships are expanded. Every recorded relationship between
visible subjects appears automatically,
including relationship types that were not used to reveal those people.
This separates choosing whom to discover from understanding their connections:
using the existing global relationship exclusions for both would hide links
such as Aisha's connection to Abu Bakr after revealing wives and fathers-in-law.
