# Mission set: evolve the design, not author or review batches

Chose design evolution over authoring batches, reviewing agent output, or
explaining the pipeline to others. Lessons should therefore teach seams and the
arguments behind them, with the success test being predictive — given a proposed
model change, name what breaks and which existing rule already answers it.
Procedure (which command to run when) is reference-card material, not lesson
material. See [[MISSION.md]].
