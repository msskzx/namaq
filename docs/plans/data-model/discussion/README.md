# The discussion behind plan.md

Four agents (two planners, two reviewers) formed the merged plan in `../plan.md`. These files are the record of how, kept so a decision in the plan's decision table can be traced to who proposed it and who agreed.

| File | What it holds |
| --- | --- |
| `axes.md` | The 13 decision axes every agent answered (X1-X13). |
| `round1-positions.json` | Each agent's position on each axis after reading both revised plans: which plan's design it preferred, the reason, and its condition. |
| `round2-input.json` | The contested axes and the 12 extra issues (E1-E12) as sent to round 2. |
| `round2-<agent>.json` | Each agent's merged proposal per contested axis, any dissent, and its decision on each extra issue. |
| `signoff-<agent>.json` | Each agent's sign or dissent per axis on the merged plan, and the 18 fidelity notes. Planner A, who drafted the plan, has no sign-off file. |
| `final-responses.json` | How each sign-off note was answered in the plan. |

Agent names: `plannerA` (plan A, top-down from the hadith case), `plannerB` (plan B, bottom-up from today's model), `reviewerA` (reviewed plan A), `reviewerB` (reviewed plan B).
